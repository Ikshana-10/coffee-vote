# ☕ The Cozy Roast - Voting Application

An interactive, responsive single-page web application built as part of my internship assignments. This project demonstrates core backend API design, database state updates, and dynamic frontend rendering.

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS (via CDN)
- **Backend:** Node.js, Express.js
- **Database:** SQLite (via `sqlite3` driver)
